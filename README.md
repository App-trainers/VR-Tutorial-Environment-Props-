# VR Spacecraft Environment – AppTrainers

## 📌 Overview
This project contains a **3D virtual reality environment** created specifically for an educational **VR tutorial series** on the **AppTrainers** YouTube channel.

The environment represents the **interior of a spacecraft in outer space**, with detailed props and simulation elements suitable for immersive VR experiences.

🔗 **Watch the tutorial playlist here:**  
https://youtube.com/playlist?list=PL4f5DAWA0KVueCLJX_2K8_QljtAbP2zRA

---

## 🚀 Project Purpose
- Support the **AppTrainers VR tutorial series**
- Demonstrate how to build and interact with a VR environment
- Provide a real example of VR simulation design

---

## 🧠 Features
- VR-ready spacecraft interior
- 3D props optimized for VR performance
- Scene designed for Unity XR / VR setups
- Used in step-by-step YouTube tutorial by AppTrainers
